# 逃离遵化益众

一个基于真实校园布局的同人文字冒险小游戏(纯前端,无需服务器)。深夜的益众中学里,你从空教室醒来,要在 SAN 值归零之前穿过教学楼、混出校门。

## 怎么玩

1. 打开 `index.html`(手机竖屏体验最佳);
2. 主页「开始游戏」填写角色卡(姓名/年级/级部/班级;阵营目前只有学生可选);
3. 出生在自己班级的教室里,每局班级位置随机生成;
4. 右上角四个按钮:**地图 / 行为 / 背包 / 周边生物**,再下面是设置;
   - 地图默认显示你所在建筑的**楼内视图**,右上角可切**全景**;
   - 绿色方格点位可点击移动,也可以用底部**方向键 ▲◀▶▼**(优先走走廊,右侧的"门"要按 ▶ 通过);
   - 楼梯上有上下楼按钮;教室门口可进入教室触发剧情;
   - 操场是九宫格,上两排和下一排背景不同;下方中心可进横段楼;
5. **校门**:第一次可以选「冲出去!(成功率 20%)」,失败会被门卫抓回楼里且**这局不能再冲**;
   去教学楼的随机剧情里找**出门证**(背包 🎫),在大门出示即可离开;
6. 左侧无底色状态栏显示:名字等级 / 经验条 / 身份 / 属性(血量·精力·SAN)/ 状态(含剩余时间);
7. 存档自动保存在浏览器本地;主页左上角「存档」继续,旁边「更新日志」可查各版本改动。

## 战斗 / 等级 / 背包 / 状态

- **遭遇**:操场只刷学生;教学楼刷老师/学生/诡异(形象先用 ? 表示)。善良不还手,中立被打会还手,邪恶主动攻击。
- **战斗**:伤害 = 己方攻击 − 对方防御;对方血量归零会逃走并掉落物品、给 5 点经验。
  战斗面板上方是血量与属性,右侧攻击/逃离(剧情过完才出现逃离)。
- **等级**:1-10 级,名字右侧显示等级颜色,经验条在名字下方;升级需要 5n 经验;
  攻击 1/3/5/10/20/30/40/50/70/100,防御 0/2/5/8/12/17/25/35/50/65。
- **物品**:药剂随机回 1-20;笔/试卷收藏;烧饼两分钟内每 7 秒回 5 血 5 精力并 SAN-20;出门证用于校门。
- **行为**:休息(+10 精力)与冥想(+5 SAN)各需读条 3 秒、可中途中止、冷却 30 秒,各 +1 经验。
- **精神状态**:SAN<40/20/10 时上限降为 80/60/30;SAN 归零进入**诡化**,还能操作约 3 次,之后触发结局「迷失」。
- **周边生物**:遇到张云祥/值周生这类剧情人物后会留在你身边,可通过左侧按钮查看身份并决定是否攻击,离开点位后消失。

## 文件结构

```
index.html          入口(单页应用)
css/style.css       玻璃质感 UI(深/浅色主题)
js/config.js        地图布局、班级分布、剧情事件、生物与物品数据
js/audio.js         WebAudio 合成纯音乐(晨光钢琴/夜雾氛围/星夜电钢)
js/save.js          本地存档与设置
js/game.js          主逻辑(地图/战斗/等级/背包/状态/校门)
assets/images/      场景图与角色头像
```
