# 逃离遵化益众

一个基于真实校园布局的同人文字冒险小游戏(纯前端,无需服务器)。深夜的益众中学里,你从空教室醒来,要在 SAN 值归零之前穿过教学楼、走到大门口,逃离学校。

## 怎么玩

1. 打开 `index.html`(手机竖屏体验最佳);
2. 主页点「开始游戏」,填写角色卡(姓名/年级/级部/班级;阵营目前只有「学生」可选);
3. 出生在自己班级的教室里,每局班级位置随机生成;
4. 右上角「地图」打开地图:
   - 默认显示**你所在建筑的楼内地图**,右上角「🌐 全景」切换全校;
   - 绿色点位可点击移动(只能走到相邻点位),也可以用底部的**方向键 ▲◀▶▼** 前后左右走;
   - 站在楼梯上有「上楼/下楼」按钮;站在教室门口可以「进入教室」触发剧情;
   - 操场 1F 可从 8字楼右侧「侧门」进入,里面上、下两个点位;
   - 你在几层,地图就显示几层(大号楼层徽章);
5. 走到 1F 大门口,点「冲出去!」通关;路上会遇到同桌小雨、值周生、门卫老赵,还有拦着不让学生离开的张云祥老师;
6. 左上角状态栏:血量/精力/SAN/姓名/形态;顶部是游戏时钟(2026.10.30 06:00 起,现实 1 小时 = 游戏 12 小时);
7. 存档自动保存在浏览器本地,主页左上角「存档」可继续/删除。

## 文件结构

```
index.html          入口(单页应用)
css/style.css       科技感简洁 UI(深/浅色主题)
js/config.js        地图布局、班级分布、剧情事件
js/audio.js         WebAudio 合成纯音乐(晨光钢琴/夜雾氛围/星夜电钢)
js/save.js          本地存档与设置
js/game.js          主逻辑(双视图地图/方向键/教室与操场剧情/时钟/打字机对话)
assets/images/      场景图与角色头像(用户提供为主)
```

## 发布到 GitHub Pages(微信里就能打开)

网页上传方式:

1. 登录 GitHub,新建仓库(Public),如 `yizhong-escape`;
2. 仓库 → Add file → Upload files,把本目录所有文件原样传上去;
3. Settings → Pages → Source 选 `main` 分支、根目录 → Save;
4. 等 1 分钟,访问 `https://你的用户名.github.io/yizhong-escape/`,发到微信即可打开。

命令行方式:

```bash
git init && git add -A && git commit -m "逃离遵化益众"
git remote add origin https://github.com/你的用户名/yizhong-escape.git
git push -u origin main
# 再到 GitHub 网页 Settings → Pages 选 main 分支
```
